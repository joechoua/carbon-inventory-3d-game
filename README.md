# 小綠的碳盤查任務 II：3D 排放源尋寶

[立即遊玩](https://joechoua.github.io/carbon-inventory-3d-game/)

五個場景、八種資料線索：工務所讀電表、公務車開始及停止加油、核對材料送貨數量、開關水龍頭讀表、配對清運文件。

點地標讓小綠走到目的地，抵達後再點地標開啟關卡。完成後「繼續探索」回到工地，自行選擇下一站。砂石車與公務車先進場停妥，小綠再移動。

使用原生 WebGL，無外部程式依賴。進度保存在瀏覽器本機；沒有帳號或資料上傳。教材數字為示意，混凝土 9.0 m³ 延續訓練案例。

## 專案結構
- index.html：介面與樣式
- game.js：發布用程式
- src/learning.js：教材與圖鑑
- src/activities.js：關卡及移動流程
- src/engine.js：3D 模型、車輛及步行動畫
- assets/：角色圖與製作說明

更新來源後依 learning、activities、music、engine 順序串接產生 game.js。

本版完成程式語法、部分關卡模擬與幾何距離檢查。手機、瀏覽器與動畫外觀仍需實機驗證。

## 配樂
原創 Web Audio 程序配樂，92 BPM，柔和撥弦式旋律與和弦；完成關卡播放提示音。第一次操作後播放，右上可靜音，切到背景暫停，偏好保存在本機。無外部音樂檔或取樣。
