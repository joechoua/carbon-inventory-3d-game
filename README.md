# 小綠的碳盤查任務｜3D 工地探索

約五分鐘的繁體中文互動教育遊戲。玩家在可旋轉、縮放的 3D 工地完成四個資料蒐集與查證任務：

**立即遊玩：<https://joechoua.github.io/carbon-inventory-3d-game/>**

1. 找出能支持實際交貨量的原始單據。
2. 核對混凝土交貨量 9.0 m³ 與原始單位。
3. 將錯誤申報的 90.0 m³ 修正為 9.0 m³，並保留修正紀錄。
4. 以原始單據、修正後申報表與差異說明完成查證交接。

## 操作

- 點選工地地標或右側任務卡開始。
- 拖曳旋轉，使用滾輪或按鈕縮放。
- 支援手機、鍵盤操作與瀏覽器內進度保存。
- 完成後可下載文字學習紀錄。

## 執行方式

直接開啟 `index.html`，或使用任何靜態網站服務。專案不需建置步驟、後端、資料庫或第三方程式庫。

## 教育內容聲明

這是「碳盤查資料蒐集與查證」教育訓練專案的互動練習。9.0 m³ 沿用既有教學案例；DEMO-001、已簽收／本期交貨、90.0 m³ 誤植及其他文件數量為遊戲情境設定。內容不能作為真實單據的新查核事實、正式碳排放計算或查證結論。

遊戲不會將作答內容傳送至伺服器；進度只保存在使用者目前的瀏覽器。
