# 公務車加油關卡

機具區流程：公務車沿道路進場，停靠於 (5, 0.1)；小綠等車停妥，再前往 (3.2, -1.0)。抵達後點地標進入加油操作。

操作：開始加油 → 停止加油 → 依停止時的公升數輸入 → 正確後取得資料卡。累計以整數十分之一公升儲存，避免浮點誤差；最多 30.0 公升自動停止。關閉視窗即停止，不在背景繼續累加。重新進入活動重新計量。

程式模擬測試通過：手動開始及停止、停止後讀數固定、錯誤答案拒絕與重試、正確答案通過、30 公升上限、關閉取消。已檢查停靠車身包圍範圍與人物半徑，站位不相交。移動途中不接受另一個目的地，避免車輛突然出現在行人路徑。
